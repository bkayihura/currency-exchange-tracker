# Cuurency Exchange Tracker
 
A simple website for converting currencies and checking live exchange rates.

## Features

- Convert between currencies
- View live exchange rates 
- Search currencies
- Sort currencies by name or exchnge rate 
- Refresh exchange rates
- Responsive design for mobile and desktop

## Technologies Used

- HTML
- CSS
- JavaScript
- ExchangeRate-API

## API

Exchange rates are fetched from:
https://open.er-api.com/v6/latest/USD
